Como jogar

Todo dia tem duas palavras de 5 letras. Você tem 8 tentativas para cada uma.

As bolinhas mostram quantas letras você acertou, mas não quais:

  • 1 no lugar certo
  • 2 em outro lugar
  • 2 não estão na palavra

Toque num quadrado da linha que você está escrevendo para escolher onde a letra vai. Assim dá para começar pelo fim.

Toque numa letra de um palpite já enviado para anotar: vermelho, amarelo, verde, sem cor. No teclado, segure a letra.

A palavra certa nunca tem letra repetida, então tente usar 5 letras diferentes.

Acentos não contam.
